# Archived: FCCD High School + Prestige v1.0.3 Combined Mods

The original combined v1.0.3 release was first published in the [FCCD High School Mods repository](https://github.com/wsuraiders33-maker/FCCD-High-School-Mods/releases/tag/combined-v1.0.3). Preserve the **same eight original assets** when making an archived `combined-v1.0.3` release in this dedicated Combined Mods repository.

This older release combines early high-school gameplay with Prestige-Based Dynasty v1.0.3. **It predates the High School v1.1.5 missed-field-goal return improvements** and is retained for rollback/reference.

## Variants

- Ohio Divisions I through VII (separate installers)
- Generic High School: Large, Medium and Small profiles selectable from one installer

## Features

- Prestige-based roster caps from 34 to 85
- Prestige-scaled scholarships and recruiting; expected-senior limits in-season and open roster spots in the offseason
- Improved AI recruiting, positional safeguards and automatic walk-ons
- No redshirts, four-year player progression and normal graduation
- 12-minute quarters, kickoffs from the 40 and high-school touchbacks
- Attendance and postseason calibration suited to the Ohio division or Generic school size

## Install

Windows Steam FCCD 1.6.5 only. Back up saves, close the game, return to clean stock files, extract **one** ZIP, run `INSTALL.bat` and `VERIFY.bat`. Close the game and run `RESTORE.bat` to switch versions or revert.
