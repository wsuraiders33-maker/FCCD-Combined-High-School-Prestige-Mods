# FCCD High School v1.1.5 + Prestige v1.0.3 — Combined Mods

This release brings **High School Mods v1.1.5** and **Prestige-Based Dynasty v1.0.3** together in eight independently installable packages: **Ohio Divisions I–VII** and **Generic High School** with selectable Large, Medium and Small profiles.

## What's new in High School v1.1.5

- Missed field goal kicks use the kicker's **Kick Power** and natural distance variation.
- Missed field goals remaining in play can be **returned**, using adjusted punt-style mechanics.
- Kicks reaching the end zone are touchbacks at the 20-yard line.
- On-field visualization, return yardage, play-by-play descriptions and game-clock accounting were updated.

## Other features retained

- 12-minute quarters, kickoffs from the 40-yard line and high-school touchback rules
- Four-year freshman-to-senior progression with no redshirts
- School-size-specific stadium and attendance settings, including Ohio division calibrations
- Prestige-based roster caps of 34–85 players
- Prestige-scaled scholarships, recruiting limits and adaptive recruit pools
- AI recruiting, positional-depth safeguards and automatic walk-on support

## Installation / restoration

1. Back up saves and close *Football Coach: College Dynasty*.
2. Restore clean **Steam FCCD 1.6.5** original files with the prior mod's `RESTORE.bat` if necessary.
3. Fully extract **one** combined ZIP.
4. Run the top-level `INSTALL.bat` (Generic users select Large, Medium or Small).
5. Run the top-level `VERIFY.bat` before launching the game.
6. To uninstall or switch variants, close the game and run the matching `RESTORE.bat` before installing something else.

**Do not stack different combined packages or install standalone High School or Prestige mods over a combined installation.** Ohio packages require the matching Steam Workshop Ohio high-school universe.

## Testing and compatibility

The creator reported that all eight combined test packages worked in-game. For release packaging, the game engine and installer payloads remained byte-identical; only documentation/metadata changed. ZIP integrity was checked. The repackaged installers were not independently exercised in-game.

Supported: **Windows Steam FCCD 1.6.5** matching the installers' expected original file hashes. Mac compatibility is not verified.
